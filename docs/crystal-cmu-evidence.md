The Crystal rewrite changes preserve bar boundaries, retain accepted turns during repairs, and add inspectable pronunciation evidence without weakening the other acceptance checks. The final source uses grader 8, shared contract 2, and prompt 4. This report records isolated tests and retained-data replay; it does not claim a production rewrite success rate.

Slash-separated model bars now become semicolon pauses before speech grading. Short landings such as “I stay near / Have no fear” survive this conversion. Whole-only retries regrade retained candidates under the current contract, keep accepted neighboring wording immutable, and request one bounded group of failed original turn IDs. They retain complete sources and candidates when admission is deferred or the reply ceiling is insufficient. Legacy cached whole candidates are revalidated before that ceiling; already valid long work needs no new model request. Repeated unchanged failures retain their existing review references, while each actual model attempt remains a separate learning outcome.

The new pronunciation provider reads only the bundled [CMUdict snapshot](../vendor/cmudict/provenance.json), pinned to commit `74790861f652b15e4ac49015a90074ad62a27690`. Its dictionary SHA-256 is `81917843c7f44ce2b094ac63873c2c7a4cf802040792c455ba3ca406891c3d22`; the original license, README, and provenance ship beside it. There is no runtime download. Missing, oversized, or modified data supplies no new evidence, leaving the prior rhyme checks available.

Only actual final lexical words of existing bars receive new proof. Trailing numbers and stop words are not silently removed. The provider matches all phonemes from the final stressed vowel, preserves the existing word-equivalence and suffix-depth safeguards, and counts a repeated unordered word pair once. The existing long-line threshold still applies. Full pronunciations, matched endings, bar positions, dictionary version, and hash are retained in each report. Examples include `there/care → EH R`, `key/fee → IY`, and `breakthrough/view → UW`. A repeated “man” tag and a shared unstressed suffix such as `walking/cooking` provide no new proof.
