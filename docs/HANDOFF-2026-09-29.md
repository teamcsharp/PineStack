## How the waves are deployed (repeatable)
- Stage in `/tmp/delivNN` with `build_wave.sh <name> <steps>` → `/tmp/<name>dry`. Steps: `run` / `copy` lines.
- Container tests: `docker cp` a dry tree to /tmp/wX; `docker exec -w /tmp/wX -e PYTHONPATH=tests:. -e SPARK_AGENT_DATA_DIR=/tmp/wX_data spark-agent python3 -m unittest …`.
- `deploy_wave.sh <name>`, then `python3 tools/deploy-at-radio-gap.py --restart` (check the ComfyUI queue is empty first).
- Commit, `git branch -f main master`, then publish: `~/PineStack` fetch + ff-merge, and push explicit SHAs to main and master.
- Kiosk: sync pine-views from desktop/renderer (hand-copy new files and add them to ViewAssets.kt), gradle `assembleDebug`, `deploy.sh --no-build`, then commit and push to `pinestack android/main`.
- Tables: `PUT /api/system3/tables/{id}` with `Authorization: Bearer $SPARK_AGENT_API_KEY`.
