# Book Mode

The DGX Spark is the source of truth for book discovery, text extraction, vector indexing, narration, title covers, and saved progress. Desktop and tablet clients use the authenticated book APIs.

The read-only NAS share `//10.89.1.125/Downloads` is mounted on the DGX at `/home/ehm_eckx/pinevoice-stack/spark-agent/data/book_sources`. Docker exposes it as `/books:ro`; `PINE_BOOK_FOLDERS=/books/Epub:/books/PDF` selects the two requested source folders. The host mount is persisted in `/etc/fstab` using the existing NAS credential file. Originals are never edited.

Discovery runs independently of vector processing every five minutes by default. Change the scan interval in Book Mode or request an immediate refresh. New or changed EPUBs and PDFs are queued for vectorization; files arriving during an ingestion pass join that pass. An unavailable share preserves the existing catalog and vectors. Reconnection is detected by later scans. Discovery does not require an open client. The vector worker continues in the background, so a large collection can be read before every book has finished indexing.

Click the book icon above the Script pane or open the BOOKS rail tab to browse the library. Opening either surface leaves Pine Box FM playing. Browsing titles, previewing a book, selecting its cover or title, and adjusting reader preferences do not start narration. Both surfaces share the same selected book and progress; the inline library keeps the station player and feed visible. The alphabetic shelf scrolls horizontally through title covers, with the selected book highlighted.

Select a cover or title, then click the round start button at the top or Read in the reading controls. Read on a shelf title selects that book and starts narration after any required resume confirmation. A selected title is required before playback can activate Book Mode. FM pauses when reading starts, while the background banks continue working. The round button also pauses narration; use Back to Pine Box FM to stop Book Mode and restore the station's prior pause state. Closing the library icon or switching views only changes the visible UI.

Use Find in book to search for a phrase. Matching sentences are paged; opening a match browses its surrounding section without advancing or seeking playback. Choose Read from here or double-click a sentence to begin narration there. Resume requires confirmation, and only completed, ordered playback receipts advance the saved position. Scrolling and seeking do not mark unread sentences as heard. A changed source edition requires an explicit restart.

Choose one reader, cycle through the cast, or use weighted roulette. System 3 supports a Book reader node with reader order and routing; its inspector can apply the node to Book Mode. Speeds are 1, 2, 4, 6, 8, and 16 times normal. Sentence gaps, crossfade, and read-ahead are configurable. Right-click a sentence for pronunciation guidance, reports, and spoken replacements; an optional meaning restricts reuse to matching contexts. Sentence-relevant video and reading status remain available across views.

Read mode preserves the source sentence. Discuss mode adds grounded cast commentary, with either the current book or the indexed book universe as context and optional topic web research. Book questions return supporting quotes and source references. Covers and book previews also appear in the manuals database. Book previews open a two-page reader with page navigation and zoom while Pine Box FM continues. PDF previews render the original printed pages on demand, preserving their typography, images, and page numbers. EPUB previews preserve publisher styles, illustrations, and embedded fonts; chapters reflow into facing pages sized for the preview window. EPUB page numbers describe that reflowed chapter layout rather than fixed printed pages. Chapter navigation moves between the book's original sections. Preview navigation and zoom do not select a title for narration, start Book Mode, or change saved reading progress. Image-only PDFs can be previewed but need searchable text/OCR before useful extraction and vectorization.

The persistent `data/books/catalog.json` cache records titles and authors from EPUB package metadata or PDF document metadata, with a cleaned filename as fallback. Discovery reuses metadata for unchanged files and refreshes it when the source file or metadata version changes. Generated title cards are cached per book as `cover.svg` and `cover.json`; changes to the title, author, source stamp, format, or cover version invalidate the cached card. The catalog API provides a signed, versioned cover URL for image rendering, with the authenticated JSON cover API as a compatibility fallback. A readable title card remains visible when an image cannot load. These cards present the books' actual catalog titles; they do not require embedded publisher cover art.

Narration is cached on the core, and switching or seeking cancels obsolete preparation. One client owns the playback session at a time.

Verification: `python -m unittest discover -s tests -p test_book_mode.py`, the existing library and System 3 graph tests, and `electron tests/test_book_mode.cjs`. The Electron harness checks browsing without activation, explicit reading, cover rendering, desktop/tablet layouts, and continuous 16x playback with delayed bookmark writes. `tools/probe_book_mode.py` is a read-only live deployment check, run inside the core container so it can use the existing API key without printing it.

Tablet assets are included in the Android project; an installed tablet needs a rebuilt, platform-signed APK through `deploy.sh` to receive updated assets. Desktop renderer JavaScript is mirrored and staged for an explicit shell reload or restart; refreshing an embedded station webview alone does not reload Book Mode. Backend Python changes require restarting the spark-agent service.
